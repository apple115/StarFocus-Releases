# 星时 · Star Focus

极简桌面专注计时器，用专注时间逐步建设自己的星系。

本仓库只提供安装包、更新清单和使用说明，不包含应用源代码。

## 下载

[下载最新版本](https://github.com/apple115/StarFocus-Releases/releases/latest)

当前提供 macOS Apple Silicon（M 系列芯片）版本，要求 macOS 13 或更新系统。Windows 与 Intel Mac 安装包尚未在此发布。

解压后将「星时.app」放到 Applications，再打开。当前为未公证测试版本。

## 使用

- 菜单栏单击开始/暂停，右键快速设时、提前结束或跳过休息。
- 支持标签、日周月统计、程序化星球与建设。
- 专注数据保存在本机。
- 从 0.2.2 起接入公开签名更新源，后台检查并下载，计时结束后可重启更新。旧版没有更新源的用户需先手动安装一次。

更新清单和安装包使用 Ed25519 签名；客户端内置验证公钥。更新签名不等于 Apple 公证。
